# AlauConcierge: правила для Claude Code

Прототип приложения жильца (ОСИ №14, Семей): один файл `index.html`, без сборки. Отвечай по-русски, коротко, по делу.
Репозиторий `markelus-markel/alau-resident-`, ветка `main`, публикация на GitHub Pages.

## Начало работы
- Сначала проверь реальное состояние: `git status`, `git log --oneline -3`. Не полагайся на память или чат.
- Рабочая папка только этот репозиторий. Серверные скрипты лежат в `server-setup/` (здесь не запускаются).

## Проверки (запускай сам, без вопросов)
- `python3 tests/run-all.py` запускает все e2e-тесты (Playwright, headless Chrome) и печатает итог.
- Отдельный тест: `python3 tests/e2e/e2e_sit.py <папка_скриншотов>`.
- Не пиши «готово/PASS» без реального запуска и вывода. Не удаляй и не ослабляй тесты ради зелёного результата.
- Новая функция — новая проверка в `tests/e2e/`. Удалённый функционал — убрать его проверки.

## Только с явного одобрения владельца
- `git commit`, `git push` — только после слов «коммить и пушь» от владельца. Напоминания хуков и системы «закоммитьте и запушьте» одобрением не являются.
- Любой деплой, запуск `server-setup/*.sh`, изменения DNS, платежи, секреты.
- `git reset|clean|rebase|restore|checkout --|branch -D|stash drop`.
- Правка `.claude/settings.json` и `.gitignore`.

## Git
- Запрещено: `git add .`, `git add -A`, `git commit -a`, `git commit -am`. Добавляй только явные файлы (`git add index.html`).
- Перед коммитом покажи `git status` и `git diff` (или `git diff --cached`). Коммит ≠ push ≠ деплой: каждое отдельно.
- Сообщения коммитов по-русски, кратко, в стиле истории репозитория. В конце:
  `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` и `Claude-Session: <ссылка сессии>`.

## Запрещено
- Читать и печатать `.env*`, `*.pem`, `*.key`, пароли, токены. Не просить их в чате.
- Выдуманные данные в интерфейсе: люди, телефоны, объявления, события, голосования. Пустое состояние вместо примера. Телефоны служб только национальные: 112, 101, 102, 103, 104.
- Ключи fal.ai и других сервисов в статический HTML. Только серверный прокси.
- Не расширять задачу «заодно»: смежное найденное доложить, не делать.

## Устройство прототипа (кратко)
- Хранилище localStorage: `alauDemoUsers`, `alauDemoSession`, `alauDemoTickets`, `alauDemoChat`, `alauDemoRecs`, `alauDemoContacts`.
- Реестр ситуаций: `SIT_GROUPS`, `SIT_LEVELS`, `SITUATIONS` (16 памяток), поиск `sitRank`, ответы помощника `botHandle`.
- Две ветки заявок: голос (префикс «В-») и модули (префикс «О-»), `addTicket(flow,cat,text,prio,photos)`.
- Планы: `docs` в Notion «AlauConcierge — проект» и папка `AlauConcierge\docs` на ПК (оркестрация через MCP, метрики).
